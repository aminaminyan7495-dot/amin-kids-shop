# فروشگاه آنلاین پوشاک امین

نسخه اولیه کامل و رسپانسیو فروشگاه:
- صفحه اصلی
- دسته‌بندی محصولات
- جستجو
- فیلتر و مرتب‌سازی
- صفحه جزئیات محصول
- انتخاب سایز
- سبد خرید با localStorage
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- لینک اینستاگرام و کانال بله

## اجرا
فایل `index.html` را با Chrome باز کنید.

## مرحله بعد برای سایت واقعی
برای فروش واقعی باید بک‌اند، دیتابیس، پنل مدیریت، درگاه پرداخت، ثبت سفارش و سیستم موجودی به آن متصل شود.
